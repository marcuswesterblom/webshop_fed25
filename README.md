# 🛒 Webshop — FED25 School Project

This is a **Webshop application** built as part of a school assignment in the **Frontend Developer 25 (FED25)** program.

The goal of the project was to practice core frontend skills such as **TypeScript, DOM manipulation, event handling, responsive layouts, and interactive UI components**, using modern tooling.

---

## 🚀 Features

- Browse products
- Add items to a shopping cart
- Remove items from the cart
- Dynamic order summary with live updates
- Interactive modals with overlay
- Responsive layout for different screen sizes

---
## 💻 My Responsibilities

- Implemented the **entire checkout page**, including structure, styling, and logic using **HTML, SCSS, and TypeScript**
- Built the **shopping cart functionality** from scratch using **HTML, SCSS, and TypeScript**
- Implemented **add/remove product logic** in the cart
- Managed cart state using **localStorage**
- Ensured cart contents persist between pages and sessions
- Passed selected products and cart data from the cart to the checkout page
- Handled checkout-related logic such as displaying order summaries and totals
---

## 🧠 What I Learned

- TypeScript for type-safe frontend logic
- DOM manipulation and event handling
- Structuring a frontend project
- Working with responsive layouts using SCSS
- Creating interactive UI components and animations
- Using a modern development environment with Vite
